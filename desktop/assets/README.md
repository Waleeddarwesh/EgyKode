# Store assets

Screenshots and Store artwork only. **No app content.**

App icons are not here on purpose: they are generated by the website from the
brand mark (`apps/web/app/icons/`), so the Store package and the site can never
show different marks. PWABuilder derives the Store tile set from those.

Screenshots should be captured from the *installed* app rather than a browser,
so the window chrome is genuine. The shot list is in `../store/listing.md`.
